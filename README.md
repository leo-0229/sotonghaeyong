# 소통해용

진주 문산중학교 학생 자치 커뮤니티입니다. GitHub Pages 화면과 Supabase 로그인·데이터베이스를 사용합니다.

- [사이트 열기](https://leo-0229.github.io/sotonghaeyong/)
- **[통합 이용·운영 가이드](guide.md)**: 레벨별 권한, 이용 규칙, 계정 발급·분실, 실행·배포 방법
- 사이트 로그인 후 왼쪽 **레벨별 이용 가이드**에서도 확인할 수 있습니다.

## 로컬 실행

```powershell
cd C:\Users\user\Desktop\mpms
npm.cmd ci
npm.cmd run dev
```

브라우저에서 `http://127.0.0.1:3000`을 엽니다. 실제 로그인 연결과 검사·배포 명령은 [guide.md](guide.md)를 따릅니다. 실제 회원 정보·비밀번호·서버 비밀키는 저장소에 올리지 않습니다.
