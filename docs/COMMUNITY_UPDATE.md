# 소통해용 게시판·소통 기능

현재 정책은 이 문서가 이전 기획·초기 배포 안내보다 우선합니다.

- 저장소: https://github.com/leo-0229/sotonghaeyong
- 사이트: https://leo-0229.github.io/sotonghaeyong/

## 게시판과 글 수정

첫 화면은 전체 글 목록입니다. 작성자, 한국 시각의 작성 일시, 조회수, 하트를 표시하며 본문에서 작성·수정 시각을 구분합니다. 학교 행사도 목록형으로 제공합니다. 왼쪽은 학교 소식 세 항목을 기본으로 펼치고 나머지는 접히는 메뉴로 정리했습니다.

게시판별 말머리를 선택합니다. 분실물은 **찾아가용 / 찾아용 / 찾았어용**, 질문은 **궁금해용 / 해결됐어용**입니다. 본인 글의 제목·내용·게시판·말머리를 수정할 수 있고, 원래 작성 시각과 수정 전 이력을 남깁니다. 운영진이 숨긴 글은 작성자가 다시 공개할 수 없습니다.

글과 댓글에는 계정당 하트 한 개를 누르거나 취소할 수 있습니다. 다른 회원에게 누른 사람의 계정 목록을 공개하지 않습니다. 댓글 아래 한 단계의 답글을 작성할 수 있습니다.

## 노래 추천

왼쪽 게시판 메뉴와 게시판 탭의 **노래 추천**에서 노래 제목·가수·추천 이유를 작성합니다. 이 게시판은 말머리 입력·표시·필터를 사용하지 않습니다. 기존 글의 말머리도 제거하고 서버에서 빈 값으로 저장합니다. 글 수정·하트·댓글·대댓글·삭제·신고를 기존 게시판과 같이 사용합니다. 외부 링크·욕설·정치 관련 표현·회원 이름 검사는 유지합니다. 운영 서버에 예시 노래나 글을 자동으로 넣지 않습니다.

## 내용 검사와 자동 승인

규칙 검사에 걸리지 않으면 API 키 없이 바로 자동 공개합니다. 욕설·혐오·성적 표현·교사 호칭·정치 관련 표현·외부 링크·전화번호·알려진 비방 표현은 검토 대기로 처리합니다. 수정한 글, 댓글, 공개 건의와 답변에도 같은 원칙을 적용합니다. 자신의 대기 글을 직접 수동 승인할 수 없습니다.

AI API를 사용하지 않으며 외부 AI로 글을 전송하지 않습니다. 서버에서 검사한 결과만 저장 함수에 전달하고 일반 회원이 자동 승인 여부를 직접 지정할 수 없도록 제한합니다. 이전 승인 대기 글은 일괄 공개하지 않으며 기존 운영진 검토를 유지합니다.

띄어쓰기·숫자·기호·보이지 않는 문자·한글 자모 분리·영문 자판 입력을 정규화해 알려진 표현을 비교합니다. 웃음·울음·짧은 초성 표현은 폭넓게 허용합니다. 규칙 사전이 모든 신조어·문맥을 완벽히 판단하지 못하므로 운영진 검토와 신고를 유지합니다. 일반적인 성적 지향·정체성 자체를 욕설로 단정하지 않습니다. `쌤·썜·선생님·선생·교사`가 포함되면 검토 대기로 보냅니다. 교사 성함 명단을 별도로 수집하지 않습니다. 교사도 등록 회원이면 회원 이름 검사 대상입니다.

## 은어·정치인·회원 이름과 공개 상태 안내

`재기하다·여시·펨코·일베·디시·운지·우흥·예아·북딱` 및 관련 변형을 승인 대기로 보냅니다. `북·딱`은 독립 단어로 쓰이거나 `북딱` 같은 조합이면 보류하며, `노트북·딱정벌레` 자체는 이 사유로 보류하지 않습니다. `새끼` 자체를 욕설 사전에 넣어 `이1새1끼` 같은 표기도 검사합니다.

일반 이름 사전으로 차단하지 않습니다. 정치인 이름은 기존 정치 관련 명단을 따르고, 회원 이름은 `moderation_member_names()`로 서버에서 읽어 글·댓글·건의와 답변에 적용합니다. 회원의 표시 이름 전체와 성을 제외한 두 음절 이상 이름 부분을 검사합니다. 띄어쓰기·숫자·기호·유니코드와 한글 영문 자판 우회도 검사하며, 명단에 없는 일반 이름이나 가수 이름은 이름이라는 이유만으로 보류하지 않습니다. 회원 목록은 소스·정적 사이트에 복사하지 않고 일반 회원에게 이름 검사 전용 RPC를 허용하지 않습니다. 명단 조회에 실패하면 자동 공개하지 않고 검토 대기로 저장합니다.

L1~L5와 공식 게시판 모두 작성·수정·댓글에 같은 규칙을 적용합니다. 작성자가 운영진이어도 검사 사유가 있으면 승인 대기입니다. 작성자 본인과 검토 운영진에게는 대기 본문이 보이므로, 화면에 **아직 공개되지 않은 글**이라는 안내를 표시합니다. 다른 일반 회원의 전체 게시판·검색에는 보이지 않습니다. 다른 운영진의 수동 검토는 계속 제공하며 본인의 대기 글을 직접 승인할 수 없습니다.

## 글·댓글 삭제

작성자는 자신의 게시글과 댓글을 삭제할 수 있습니다. 다른 회원의 내용 강제 삭제는 L4·L5만 가능하며 5자 이상의 사유를 입력합니다. 화면에서 확인 체크 후 확정하고 서버 RPC에서도 로그인·작성자·등급·사유를 다시 검증합니다. L3는 승인·반려 업무를 유지하지만 다른 회원의 내용을 강제 삭제할 수 없습니다.

게시글 삭제는 본문·수정 이력·댓글·하트·신고를 함께 제거합니다. 댓글 하나를 삭제하면 본문·하트를 제거하고 다른 회원의 답글은 일반 댓글로 남깁니다. 운영 기록에는 처리자·시각·대상 ID·강제 삭제 사유만 남기고 삭제 본문을 복사하지 않습니다. 삭제 내용은 앱에서 복구할 수 없습니다. 기존 게시글을 자동으로 일괄 삭제하지 않습니다.

## 댓글 신고

공개된 다른 회원의 댓글·대댓글에서 **댓글 신고**를 눌러 5~1000자의 사유를 접수합니다. 같은 회원이 같은 댓글을 여러 번 신고해도 한 건만 생성하고, 회원당 10분에 새 신고 10건까지 허용합니다. 비공개·승인 대기 댓글은 ID를 알아도 신고할 수 없습니다. 신고 사유는 신고자와 L3 이상 검토 운영진만 읽으며 일반 회원이나 댓글 작성자에게 공개하지 않습니다.

관리 화면의 **댓글 신고 접수**에서 L3 이상이 확인 완료·기각을 처리합니다. L4·L5는 사유를 적고 강제 삭제할 수 있습니다. 댓글 삭제 시 연결 신고도 정리합니다. 신고만으로 자동 삭제하지는 않습니다.

## 외부 욕설 자료

사용자가 지정한 [korean-profanity-resources](https://github.com/Tanat05/korean-profanity-resources)를 참고하고, 원본에서 MIT 라이선스를 확인한 [Korcen](https://github.com/Tanat05/korcen)의 고정 버전 `eecd9763dbdccce3dc96ddb578ef0b6396058fa9`에서 한국어 욕설 570개·성적 표현 124개·영문 표기 24개를 선별해 기존 사전에 더했습니다. 한 글자·불명확한 혼합 표기·정체성 자체를 뜻하는 단어는 제외했습니다. 출처와 변경 내용은 [고지](../THIRD_PARTY_NOTICES.md), 원문 라이선스는 `third_party/korcen-LICENSE.txt`와 배포 파일 `public/licenses/korcen-MIT.txt`에 포함합니다. 출처·라이선스가 불명확한 slang.csv와 LoL 목록을 통째로 복사하지 않았고 외부 Python 코드도 실행하지 않습니다.

## 정치 관련 표현

`좌빨·극우·극좌·페미·남혐·여혐·보수·진보·좌익·우익·좌파·우파`, 대통령·총리·국회의원·정치인·보좌관 등의 표현, 정당명, 나치·파시즘·포퓰리즘과 관련 인물 이름을 포함하면 정치 관련 사유로 승인 대기 처리합니다. 한국 역대 대통령 이름과 주요 전·현직 정치 관련 인물의 이름, 사용자가 지정한 `김현지`를 명단으로 관리합니다. 명단은 [political-rules.ts](../supabase/functions/_shared/political-rules.ts)에 있습니다. 이름 등록은 현재 직책이나 정치 성향을 단정하는 표시가 아닙니다.

띄어쓰기·숫자·기호·자모 분리·한글 영문 자판 표기를 같은 기준으로 검사합니다. 성향·찬반·발언 목적에 관계없이 검사하며 동명이인과 역사 수업의 인용도 검토 대상입니다. `보수공사`처럼 요청한 단어가 다른 뜻으로 쓰인 경우에도 보류할 수 있습니다. 일반 동사 `지나치다`와 학교의 학생회 선거·공약·투표 같은 표현은 그 자체로 정치 관련 사유에 걸리지 않습니다.

자동으로 모든 정치인·보좌진을 식별하는 기능은 아니며, 누락된 이름과 새 인물은 명단에 추가하고 서버를 다시 배포해야 합니다. 이미 공개된 글을 소급해 숨기지 않으며 새 작성·수정부터 적용합니다. 대통령 이름은 [대통령기록관](https://www.pa.go.kr/portal/com/viewMainPage.do), 주요 의회 인물은 [국가기록원에 공개된 국회 회의록](https://www.nara.go.kr/upload/namo/files/000023/국회회의록_20대_346회_14차_국회본회의_의결.pdf) 등의 공개 기록과 사용자 지정 이름을 기준으로 구성했습니다.

## 학생회 개인 채널

로그인한 회원마다 개인 대화방을 만들고 본인과 학생회 임원(L3·L4)만 읽고 답할 수 있습니다. 다른 학생은 대화방 ID를 알아도 접근할 수 없습니다. L5는 학생회 역할에 포함하지 않아 다른 회원의 채널을 일반 화면에서 읽지 못합니다. 메시지는 서버에 보관하며 전송 빈도를 제한합니다.

행사 신청·취소, 멘토링 신청·매칭, 건의 접수는 해당 개인 채널에 안내를 남깁니다. 알림에서 해당 대화방으로 이동합니다. 화면은 메시지를 주기적으로 갱신하며 이전 대화를 추가로 불러올 수 있습니다.

## 멘토·멘티 연락처

동성 1:1 학교생활 멘토링을 유지하고 활동 시간 입력은 제거했습니다. 학교생활에서 도움을 줄 수 있는 점·받고 싶은 점은 계속 입력합니다.

매칭된 두 회원이 각각 공유에 동의해야 서로의 휴대전화 번호를 볼 수 있습니다. 번호는 서버에서 AES-GCM으로 암호화해 별도 비공개 테이블에 저장하며 일반 커뮤니티 응답·관리자 명단에 포함하지 않습니다. 서버 암호화는 종단 간 암호화를 뜻하지 않습니다. 매칭 해제·계정 정지·삭제 시 공유 데이터를 정리합니다. 한쪽이 공유를 취소하면 상대의 다음 조회에서 번호가 사라집니다. 이미 상대가 복사한 번호까지 회수할 수는 없습니다.

## 공개·비공개 건의함

작성 시 공개 범위를 선택합니다. 공개 질문은 검토 후 모든 로그인 회원에게 표시하고, 비공개 질문은 작성자와 학생회 운영 담당자·학교 관리자만 확인합니다. 답변 작성은 학생회 임원(L3·L4)만 가능하며 L5도 학생회 답변을 작성하지 못합니다. 미승인 공개 질문과 답변은 별도 검토 목록에서 처리합니다.

## 학급 제출 현황

모든 로그인 회원이 각 학급의 제출 상태, 최초 제출자, 최근 수정자와 시각을 확인합니다. 제출 답변·수정 이력의 내용은 해당 학급 대표와 담당 운영진 권한을 유지합니다. 마감 후 기존 제출 건 수정은 차단하고 학생회 개인 채널로 연락하도록 안내합니다. 늦은 최초 제출 허용 여부는 업무 설정을 따릅니다.

## 운영 반영

SQL 001~021을 순서대로 적용하고 `account-access`, `moderate-post`를 배포합니다. 적용 이력에 있는 SQL은 다시 실행하지 않습니다. 멘토링 연락처 암호화는 기존 서버 전용 `TEMP_CREDENTIAL_KEY`를 사용하며 로그인 임시 비밀번호와 서로 다른 암호화 문맥으로 구분합니다.

로컬 가상 화면과 실제 Supabase에서 글 수정·원 작성 시각 보존·대댓글·하트·채널 접근 제한·상호 연락처 동의/취소·공개/비공개 건의·학생회 답변·제출 메타데이터 공개·답변 비공개·마감 차단을 검증했습니다. 원격 검증용 계정·글·신청·알림은 정리합니다.

## 참고

사용자가 지정한 [한국어 욕설 문서](https://namu.wiki/w/욕설/한국어)는 직접 접근이 되지 않아 [공개 미러](https://m.namu.moe/w/욕설/한국어)의 분류를 참고했습니다. 설명문이나 문서 전체를 복사하지 않고 학교용 규칙을 별도로 구성했습니다. [디시인사이드 게시판](https://gall.dcinside.com/board/lists/?id=programming)의 목록 구조를 확인했으며, 에펨코리아·네이버 카페는 서버 접근 제한이 있어 요청한 표형 목록·말머리·작성 시각이라는 공통 형식을 적용했습니다. 다른 사이트의 로고·이미지·스타일 코드는 복사하지 않았습니다.
